No file here comes from outside this repository but the Counter-Strike 1.6 player models above (the one exception
to the CC0-only rule, accepted by the user on 2026-10-01 because ShooterGame is an engine capability demo, not a
product for sale or distribution; they remain Valve's, not CC0): the other materials are plain colours (glTF base colour factors) or textures painted by code,
and the sounds are generated. Art from elsewhere enters only with a CC0 license and a row here naming its
source URL.

The plan named the Bot model of the removed ThirdPerson template (`ee1cdde^:Templates/ThirdPerson`) for the teams'
bodies. Its FBX files (BreathingIdle, Running, JumpingUp, ...) appear to be Mixamo exports and no CC0 license is
recorded for them, so they cannot enter this project; the characters, arms and animations above are authored by code
instead (ps2-shipping N27).
