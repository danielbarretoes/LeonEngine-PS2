# PS2 cook (host)

Host Tools produce `LPS2` blobs consumed by `leon::rhi::Ps2DrawCookedMesh`.

Until `leon-cook` gains a first-class `platform: ps2` recipe mode, stage meshes with the header documented in [ASSET_FORMATS — PS2](../../Docs/ASSET_FORMATS.md#ps2-cooked-lps2) and place them under `Projects/Ps2Lab/Content/Meshes/`.
