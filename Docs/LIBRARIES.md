# Third-party libraries

Every third-party library is an **External module** (UE: `Engine/Source/ThirdParty/<Lib>/<Lib>.Build.cs`): a folder
with a `<Lib>.Build.cmake` that calls `leon_module()`. Engine libraries live in `Engine/Source/ThirdParty/`; a plugin's
libraries live in `<Plugin>/Source/ThirdParty/`. Modules depend on them by name like on any other module
(`PRIVATE_DEPENDENCIES MiniAudio`). How External modules are built and downloaded:
[BUILD.md — ThirdParty modules](BUILD.md#thirdparty-modules).

There are two ways to obtain the code:

- **Downloaded**: `DOWNLOAD_URL` plus a pinned `DOWNLOAD_SHA256`. `Setup.bat` fetches the archive into
  `Engine/Intermediate/ThirdPartyDownloads/`, checks the hash and extracts it next to the rules file
  (`GLM/glm-1.0.1/`). The extracted folders are git-ignored. A build also downloads a missing archive while configuring.
- **Vendored**: the sources are committed in the repository next to the rules file.

## PS2

No third-party module is available on PS2: every library above is restricted to `Desktop` (or `Win64`). PS2 code uses
the PS2SDK system libraries from the pinned ps2dev Docker image, linked with `PUBLIC_SYSTEM_LIBRARIES`:

| Libraries | Linked by |
| --- | --- |
| `kernel` | `Core` (PS2 extension, EE timer), `PS2RHI` |
| `pad` | `ApplicationCore` (PS2 extension, DualShock) |
| `draw`, `math3d`, `packet`, `graph`, `dma` | `PS2RHI` |

Math on PS2 uses Core's math (`FVector`, `FMatrix`, `FMath`, …) and `FPlatformMath` (`FPS2PlatformMath::Sin256` /
`Cos256`) instead of GLM.

## Adding a library

1. Create `Engine/Source/ThirdParty/<Lib>/<Lib>.Build.cmake` (or `<Plugin>/Source/ThirdParty/<Lib>/`).
2. Downloaded: set `DOWNLOAD_URL`, `DOWNLOAD_DIR` (the archive's top-level folder) and leave `DOWNLOAD_SHA256` empty
   once; LeonBuildTool prints the hash to pin. Vendored: commit the sources under the module folder.
3. Header-only: `PUBLIC_INCLUDE_PATHS <dir>`. Otherwise define `function(LeonExternal_<Lib>)` that creates the CMake
   target (`add_subdirectory("${LEON_THIRDPARTY_DIR}" ... EXCLUDE_FROM_ALL SYSTEM)` or `add_library()`), and list it
   in `EXTERNAL_TARGETS`.
4. Restrict it with `PLATFORMS` (for example `Desktop`), and add it to the dependencies of the modules that use it.
5. Add a row to this page.
