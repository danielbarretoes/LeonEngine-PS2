# Third-party libraries

Every third-party library is an **External module** (UE: `Engine/Source/ThirdParty/<Lib>/<Lib>.Build.cs`): a folder
with a `<Lib>.Build.cmake` that calls `leon_module()`. Engine libraries live in `Engine/Source/ThirdParty/`; a plugin's
libraries live in `<Plugin>/Source/ThirdParty/`. Modules depend on them by name like on any other module
(`PRIVATE_DEPENDENCIES MiniAudio`). How External modules are built and downloaded:
[BUILD.md — ThirdParty modules](BUILD.md#thirdparty-modules).

There are two ways to obtain the code:

- **Downloaded**: `DOWNLOAD_URL` plus a pinned `DOWNLOAD_SHA256`. `Setup.bat` fetches the archive into
  `Engine/Intermediate/ThirdPartyDownloads/`, checks the hash and extracts it next to the rules file
  (`GLFW/glfw-3.4/`). The extracted folders are git-ignored. A build also downloads a missing archive while configuring.
- **Vendored**: the sources are committed in the repository next to the rules file.

## Plugin libraries

None: the engine ships no plugin.

## PS2

No third-party module builds for the PS2 since [ps2-polish](PLANS/ps2-polish.md) P5 (STB's `stb_easy_font` was the
last: the canvas draws text in the engine's `UFont`s); they are all restricted to `Desktop` (Win64). PS2 code uses the PS2SDK system libraries from the pinned ps2dev Docker image, linked with
`PUBLIC_SYSTEM_LIBRARIES` by the modules' PS2 extensions (`Engine/Platforms/PS2/Source/Runtime/<Module>/`):

| Libraries | Linked by |
| --- | --- |
| `kernel`, `patches` | `Core` (EE timer, threads and semaphores of the asynchronous IO) |
| `kernel`, `draw`, `graph`, `dma` | `PS2RHI` (the frame's VIF1 chain; the VU1 microprograms are assembled by the toolchain's `dvp-as`) |
| `pad` | `ApplicationCore` (the two DualShock 2 ports, pressure, vibration) |
| `audsrv` (and `audsrv.irx`, copied beside the ELF) | `AudioMixer` (the SPU2's voices, ADPCM) |
| `mc` | `Engine` (the memory card's save games) |

Math on PS2 uses Core's math (`FVector`, `FMatrix`, `FMath`, …) and `FPlatformMath` (`FPS2PlatformMath::Sin256` /
`Cos256`).

## Fonts and art

Third-party data that ships in the content, not code: DejaVu Sans Condensed 2.37
([dejavu-fonts](https://dejavu-fonts.github.io/), `Engine/SourceArt/EngineFonts/DejaVuSansCondensed.ttf`), the engine's
font, imported at 10, 14, 20 and 32 pixels ([ASSET_FORMATS.md](ASSET_FORMATS.md#fonts)). License: the Bitstream Vera
fonts license (a permissive license: use, copy, modify and redistribute, the fonts not sold by themselves, the name
not reused for modified fonts), the DejaVu changes in the public domain; the full text is in
`Engine/SourceArt/EngineFonts/LICENSE.txt`, and [Engine/SourceArt/LICENSES.md](../Engine/SourceArt/LICENSES.md) lists
the engine's third-party source art.

## Removed libraries

`stb_easy_font` (1.1, the HUD's bitmap font of rectangle bars) was removed in [ps2-polish](PLANS/ps2-polish.md) P5:
the canvas and UMG draw text in `UFont`s. `CheckBannedApis.ps1` (G4) rejects its name.

GLM (1.0.1), nlohmann/json (3.11.3) and Catch2 (3.5.4) were removed in P6: every module uses Core math, JSON goes
through the native `Json` module (UE's `FJsonObject` / `FJsonSerializer`), and every test is a UE automation test.

ufbx (0.14.3, vendored) and tinyobjloader (2.0.0rc13, downloaded by `Setup.bat`) were removed in
[ps2-shipping](PLANS/ps2-shipping.md) N21 with the FBX and OBJ importers: glTF (cgltf) is the only mesh, skeletal mesh
and animation format (plan decision D11). `CheckBannedApis.ps1` (G4) rejects their names.

Jolt Physics was removed in [ps2-shipping](PLANS/ps2-shipping.md) N3, with the Linux platform: the same physics
(`FPhysScene`, PhysicsCore) runs on Win64 and the PS2.

## Adding a library

1. Create `Engine/Source/ThirdParty/<Lib>/<Lib>.Build.cmake` (or `<Plugin>/Source/ThirdParty/<Lib>/`).
2. Downloaded: set `DOWNLOAD_URL`, `DOWNLOAD_DIR` (the archive's top-level folder) and leave `DOWNLOAD_SHA256` empty
   once; LeonBuildTool prints the hash to pin. Vendored: commit the sources under the module folder.
3. Header-only: `PUBLIC_INCLUDE_PATHS <dir>`. Otherwise define `function(LeonExternal_<Lib>)` that creates the CMake
   target (`add_subdirectory("${LEON_THIRDPARTY_DIR}" ... EXCLUDE_FROM_ALL SYSTEM)` or `add_library()`), and list it
   in `EXTERNAL_TARGETS`.
4. Restrict it with `PLATFORMS` (for example `Desktop`), and add it to the dependencies of the modules that use it.
5. Add a row to this page.
